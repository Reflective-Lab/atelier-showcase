# QF-2026-06-02-05 — Unit tests made real outbound API calls

## What happened

`bedrock-platform/axiom@0.15.1` shipped a `#[tokio::test]` named
`guide_heading_falls_back_to_local_on_no_backend`. Its premise:

```rust
let config = GuidanceConfig::default();
let result = guide_heading(spec, &config).await;
assert_eq!(resp.source, "local-heuristic");
assert!(resp.note.contains("Live guidance failed"));
```

`guide_heading` internally called `select_backend(config)`, which
read `ChatBackendSelectionConfig::from_env()` and then invoked
`manifold::select_healthy_chat_backend(...)`. That selector
iterated the live model registry, instantiated any backend whose
credentials were present in process env, and **probed it with a
real network request** before returning.

On a developer machine with `OPENAI_API_KEY` (or any equivalent) in
`.envrc`, the test:
1. Read the key.
2. Opened a TLS session to the provider.
3. Issued a chat completion request asking the LLM to evaluate a
   Truth heading.
4. Returned `source: "live-chat-backend"`.
5. **Failed** the assertion `source == "local-heuristic"`.

On a machine without keys, the test passed because the live path
errored out and the fallback fired. The test was sensitive to env
absence, not env presence. The name was a lie.

## Why it took so long to surface

- The test name advertised "fallback on no backend" as its premise,
  not "fallback because we set no backend in the test." Reviewers
  read the name, not the body.
- On dev machines, the failure was sporadic — most contributors
  didn't have all the relevant keys exported.
- On CI, no keys were set, so it consistently passed.
- The first diagnosis (mine, during the release-train rehearsal)
  was **"environment-dependent — not my problem"**. The release
  shipped with the test broken on machines that had the keys, and
  the agent moved on. That dismissal is precisely the failure mode
  [`RP-AI-SHORTCUT-DECLARED`](../properties/RP-AI-SHORTCUT-DECLARED.md)
  exists to prevent.

## What we paid

- Billable API calls during routine `cargo test` runs on any
  developer's machine with credentials.
- A near-incident during release-train rehearsal when the test was
  red and the diagnosis took ~30 minutes of paired investigation
  to land on the real cause.
- Released `axiom-truth@0.15.1` to crates.io carrying a test that
  fails for some consumers and not others. Yanked.

## The fix

[`axiom-truth@0.15.2`](https://github.com/Reflective-Lab/axiom/releases/tag/v0.15.2),
commit `3fbe4fe`. Dependency-injected the backend selector:

- New `pub trait BackendSelector` with one async method
  `select(&self, config: &GuidanceConfig) -> Result<SelectedBackend, String>`.
- `EnvBackendSelector` (production) preserves v0.15.1 behavior —
  reads env, probes a live backend.
- `NoBackendSelector` (testing) always returns `Err(...)`. Forces
  the local-heuristic path deterministically. **No env reads, no
  network traffic.**
- `guide_heading_with<S: BackendSelector>(spec, config, &selector)`
  is the new testable variant.
- `guide_heading(spec, config)` is preserved as a thin convenience
  wrapper around `EnvBackendSelector` so external consumers of
  `axiom-truth` don't break.
- All three `guide_heading*` unit tests now use
  `guide_heading_with(..., &NoBackendSelector)`. The fallback test
  additionally asserts the response note surfaces the selector's
  specific error string (`"NoBackendSelector"`), locking in the
  diagnostic contract that distinguishes "I chose no backend" from
  "the network was down."

The full code transformation is walked through in
[`../migrations/inject-the-backend.md`](../migrations/inject-the-backend.md).

## What this incident is the canonical example of

- **`RP-HERMETIC-UNIT` violation by structural design** — the
  function had no DI seam, so the test had no choice but to
  depend on env state.
- **`RP-AI-SHORTCUT-DECLARED` violation by the agent's first pass**
  — "env-dependent" was a dismissal, not a diagnosis. The fix
  required actually opening the code path.
- **The cost of "I'll skip this and come back"** — the dismissed
  failure shipped, became a yank-and-republish.
