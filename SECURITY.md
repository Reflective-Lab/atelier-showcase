# Security Policy

## Supported Versions

| Version | Supported          |
|---------|--------------------|
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

Report through [GitHub Security Advisories](https://github.com/Reflective-Lab/atelier/security/advisories/new) or by emailing **Kenneth Pernyer** at [kenneth@reflective.se](mailto:kenneth@reflective.se).

You should receive a response within 48 hours.

## Note

atelier is **demonstration material**, not production-grade infrastructure. The example crates exist to teach the platform, not to be deployed as-is. Any vulnerability in a worked example is an educational concern; the same vulnerability in production code would be a deployment-specific issue.

For platform-level security concerns, report against the relevant Converge or extension repo (mnemos, prism, manifold, arbiter).
