# Truths

Reserved track for the **domain-expert** audience.

This is where Truths and Gherkin specifications at the
`axiom-truth` / `helms` layer will live, alongside any worked
exemplars that show how a non-Rust domain expert specifies behaviour
that the rest of the stack honours.

The directory is intentionally empty for now — the slot is held so
that contributions land here rather than scattering across `tutorials/`
or `scenarios/`.

## Sibling tracks

- [`tutorials/`](../tutorials) — numbered learning spine for Rust
  developers new to Converge and the wider stack.
- [`scenarios/`](../scenarios) — full end-to-end domain demos
  (browse by interest, no required order).
